About #

A short version of how I work.

I'm a Computer Science undergraduate based in Hyderabad, India, focused on Retrieval-Augmented Generation and full-stack web development. I care about shipping: every project listed here is deployed and reachable from a link, not just a repository.

On the AI side, I've built and deployed RAG pipelines end to end — cleaning and chunking source documents, generating embeddings, and implementing semantic retrieval so the model answers from a specific knowledge base rather than its general training data. Most of the accuracy work went into retrieval quality (chunk size, top-k) rather than prompt wording alone.

I'm equally comfortable saying when RAG is the wrong tool: for a small, rarely-changing FAQ, a direct prompt or a cached lookup beats retrieval on both latency and cost. Being able to explain that trade-off in plain language matters as much as building the pipeline.

On the full-stack side I work with React, Node.js, Express and MongoDB — REST API design, JWT authentication and role-based access — on top of the usual fundamentals: data structures and algorithms, OOP, DBMS, operating systems and networks.

EduReach

AI college platform with a RAG chatbot

A full-stack college platform whose chatbot answers from the institution's own knowledge base. The source content is chunked with LangChain, embedded, and stored in MongoDB Atlas Vector Search, so replies are retrieved and grounded instead of guessed. Includes JWT authentication with role-based access, a React chat drawer, and an optional AI voice call-back flow.

QR Dine

Multi-interface restaurant ordering system

A QR-code ordering system deployed as four separate pieces around one API. Diners scan a table QR to browse the menu and order without signing in; the kitchen board moves tickets through New → Preparing → Ready → Served live over Socket.IO; the admin panel manages the menu and prints per-table QR codes. An AI menu assistant recommends dishes strictly from the current menu, with the API key kept server-side.
